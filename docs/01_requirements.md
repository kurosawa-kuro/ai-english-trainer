# 01 要件

正本は [`GAS版AI英会話訓練アプリ構想_ai-english-trainer.md`](./GAS版AI英会話訓練アプリ構想_ai-english-trainer.md)（以下「構想」）。ここには構想から確定した範囲だけを置き、議論と根拠は構想に残す。**状態はアイディア（未着手）で、`src/` は空である。**

## 目的

英会話コミュニティの仲間に、AI 英語訓練アプリを配る。相手に求めるのは Google アカウントと、AI を使うための鍵だけにする。鍵は Google AI Studio で発行する Gemini API のキーで、無料枠を使うのでカード登録は要らない（構想 2.2）。

**売り物は AI である。** 自由記述を書いて「意味が伝わったか」を返してもらうこと、AI と会話することが、利用者がこのアプリを開く理由である。選択式クイズと学習記録はその土台である（構想 2.2）。

## 範囲

対象:

- Google Apps Script ＋ Google Sheets で動く、一人用の英語訓練アプリ
- 配布はスプレッドシートのコピー。GitHub・Vercel・Supabase のアカウントを要求しない
- AI 採点（自由記述）、AI との会話、選択式クイズ、学習記録、設定
- **教材を利用者が自分のスプレッドシートで編集できること**（構想 4.8）
- AI が止まってもコア操作が落ちないこと（構想 4.5）

非対象:

- **関係データベースの採用**（Postgres / Supabase / Neon / Turso / Cloud SQL / MySQL）。構想 5.2 で禁止
- 音声入出力（読み上げ、録音、再生比較、STT、TTS）
- 相手によるコードの改修。相手が編集するのは教材シートだけ（構想 8.2）
- GAS 以外のクラウドへの接続
- `sample/speak-kit/` への書き込み、このリポジトリ外のリポジトリとその計画（構想 3）
- **AI 無しの状態を完成形として配ること**（構想 4.5）

## ユーザー

- 一次ユーザー: 英会話コミュニティの仲間。プログラミングはしない
- 1 インスタンスの使い方は**配布モデル A / B / C が未決**（構想 8.3）。決まるまでは A（1 人 1 コピー・各自の鍵）を前提にする
- 黒澤は初期配布と、コピー元の保守を行う。相手の環境構築に継続して付き合わない

## ユースケース

| ID | ユースケース | 成功条件 |
|---|---|---|
| UC-001 | スプレッドシートをコピーして使い始める | コピー → 初期設定 → ウェブアプリが開く。CLI もアカウント作成も無い |
| UC-002 | **自由記述を AI に採点してもらう（目玉）** | 英文を書くと 5 判定（`pass` / `pass_with_note` / `retry_target` / `retry_form` / `fail_communication`）と学習者向けの文面が返る |
| UC-003 | **AI と会話して練習する（目玉）** | セッションの開始・往復・終了が通り、言えなかった表現が候補として残る |
| UC-004 | 選択式クイズで土台を回す | 間隔反復で出題され、安定したものは出なくなる。記録から再チェックできる |
| UC-005 | 自分の教材を足す | `expressions` シートに 1 行足すと、次の出題から出る |
| UC-006 | 安心して使う | 「無料枠で動いています。料金はかかりません」と今日の利用回数が見え、回数上限か無料枠の上限（429）で理由つきで止まり、設定でいつでもオフにできる。自由記述と会話の画面に、個人情報を書かない注意が出る |
| UC-007 | AI が使えない状態でも壊れない | 鍵未設定・上限到達・設定オフのいずれでも、クイズと記録は最後まで通る。理由が画面に出る |

## Critical User Journey / Golden Path

**一次ユーザー**: そのインスタンスを使う本人。
**完了状態**: 自分で書いた英文に AI の判定が返り、それが学習記録に残っている。

売り物が AI である以上、Golden Path は AI を含む。AI 抜きで終わる道は Golden Path ではなく、UC-007 の**床**である。

| # | ステップ | 成功条件（観測可能な状態） |
|---|---|---|
| 1 | スプレッドシートをコピーし、初期設定を実行する | Google の承認を 1 回通し、ウェブアプリの URL が開く |
| 2 | Google AI Studio で発行した Gemini の鍵を設定画面に入れる | 「キー設定済み」「AI を使っています」と表示される |
| 3 | 練習で自由記述の英文を書いて送る | 採点が返る（同期）。5 判定と学習者向けの文面が出る |
| 4 | 記録を見る | その回答が履歴に残り、進捗に反映されている |
| 5 | 利用状況を見る | 設定画面に「無料枠で動いています」と今日の利用回数が出ている |

この一本が切れたらプロダクトは未達である。**1〜5 は構想 7 章の G2 に対応し、G2 が最初の出荷単位である。** G1 だけでは配らない。
