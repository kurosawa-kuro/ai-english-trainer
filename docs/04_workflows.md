## 着手する前に潰すこと（構想 12 章 優先度A）

順序に意味がある。1 が決まらないと他が固まらない。

1. **配布モデル A / B / C を決める**（構想 8.3）。他の設計がここに従属する
2. `executeAs: USER_DEPLOYING` のとき `Session.getActiveUser().getEmail()` が個人 Gmail の訪問者に空文字を返すか（実機）
3. モデル B・C で、スプレッドシートを共有せずに `USER_ACCESSING` のコードから読めるか（読めないならデータが全員に見える）
4. `Utilities.computeDigest(MD5)` が参照元の `item_key` と同じ値を出すか
5. 出題選択の JS 版が、同じ履歴に対して参照元 SQL と同じ 1 問を返すか（比較テストの形を先に決める）
6. 教材シートの検査項目を決める
7. `appsscript.json` の公開範囲が、コピー後のインスタンスにも引き継がれるか
8. 禁止の検査を置く（`Jdbc` ゼロ、`UrlFetchApp` の宛先、ロック無しの追記）

## 配布（相手の手順）

構想 8.1。**配布モデル A を前提とする。** B・C に決まれば 2〜3 が無くなり、リンクを開くだけになる。

1. 黒澤がコピー元のスプレッドシート（コンテナバインドのスクリプト同梱）を用意する
2. 相手にリンクを渡す。相手は「ファイル > コピーを作成」
3. メニューから「初期設定」を実行し、Google の承認を 1 回通す
4. 発行されたウェブアプリの URL を開く
5. 設定画面に Anthropic の鍵を入れる

CLI もアカウント作成も無い。経路はこの 1 本だけである。

## 機能の追加・変更
