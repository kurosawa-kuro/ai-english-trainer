# 08 リリース Runbook

正本は [構想](./GAS版AI英会話訓練アプリ構想_ai-english-trainer.md)。**`src/` は空で、まだ配るものが無い。** ここには、配り始めるときの手順の枠だけを置く。コマンドは着手後に埋める。

このプロダクトの「リリース」は 2 段ある。

| 段 | 意味 |
|---|---|
| **更新** | 黒澤がコピー元のスプレッドシートとスクリプトを直す |
| **配布** | 相手が「コピーを作成」して自分のインスタンスを立てる |

配布モデル A では、**コピー後に各自が独立するため、更新は既存の利用者へ届かない**（構想 8.3 の既知の弱点）。B・C なら 1 回直せば全員に届く。モデルが決まるまで、この章は A を前提にする。

## 出荷単位は G2

**G1（選択式クイズ・記録・設定）だけでは配らない。** 目玉は G2（自由記述の AI 採点）にある。G1 は G2 を載せる土台であって、出荷単位ではない（構想 7）。

## リリース前

```bash
# src/ 着手後に埋める
make test
git status --short
```

- 構想 12 章の優先度A が潰れていることを確認する
- `docs/tasks/03_active/` と `docs/tasks/04_verifying/` にリリース前の未完了 blocker が残っていないことを確認する
- [07_test_strategy.md](./07_test_strategy.md) の T1〜T8 が緑であることを確認する。とくに:
  - **T1 / T2**: `Jdbc` ゼロ、`UrlFetchApp` の宛先が `generativelanguage.googleapis.com` のみ
  - **T7**: 出題選択が参照元と同じ 1 問を返す
- `appsscript.json` の公開範囲が意図どおりであることを確認する（手操作のドロップダウンに委ねない）

## 配布後 smoke（Golden Path）

[01_requirements.md](./01_requirements.md) の Golden Path を、**実際にコピーしたインスタンスで**端から端まで 1 回通す。個別の関数が通っていても、この一本が切れていたら失敗として扱う。

| # | Golden Path ステップ | 確認方法 | 期待する観測結果 |
|---|---|---|---|
| 1 | コピーして初期設定 | 別アカウント（または別のコピー）で「コピーを作成」→ メニューの初期設定 | 承認を 1 回通し、ウェブアプリの URL が開く。シートが生成され、初期教材が入っている |
| 2 | 鍵を入れる | Google AI Studio で発行した Gemini のキーを設定画面に貼る | 「キー設定済み」「AI を使っています」と表示される |
| 3 | **自由記述を採点** | 練習で英文を書いて送る | 採点が返る。5 判定と学習者向けの文面が出る |
| 4 | 記録に残る | 記録画面を開く | その回答が履歴にあり、進捗に反映されている |
| 5 | 利用状況を見る | 設定画面 | 「無料枠で動いています」と今日の利用回数が出ている |

あわせて確認する（床が抜けていないこと。構想 4.5）:

| 確認 | 期待 |
|---|---|
| 鍵を消す | クイズと記録は通る。理由が「キー未設定」と出る |
| 設定で AI をオフ | 鍵があっても Gemini へ接続しない。理由が「設定でオフ」と出る |
| 教材シートに 1 行足す | 次の出題にその表現が出る |
| 教材シートを壊す（必須列を消す） | 出題全体が止まらず、警告が出る |

中間段（関数が通った・ビルドが緑）だけで完了にしない。

## ロールバック

- **トリガー**: 配布後 smoke で Golden Path のいずれかが期待結果に到達しない場合
- コピー元のスクリプトを前のデプロイ版に戻す（GAS のデプロイ履歴）
- **すでに配ったコピーには届かない**（モデル A）。配布済みの相手には、新しいコピー元のリンクを配り直す
- **データは戻さない。** 学習記録は各自のスプレッドシートにあり、黒澤が触れない

## 利用者側のデータ

- 学習記録と教材は利用者のスプレッドシートにある。黒澤はバックアップも復旧もしない
- スプレッドシートの版履歴が、事実上のバックアップになる
- **利用者は自分で履歴シートを書き換えられる**（構想 5.2）。「本人が壊せる自分の記録」と割り切る

## リリース後に見る

構想 12 章 優先度C。

- **鍵を設定した人の割合**（モデル A を採った場合の最重要指標。目玉に届いたか）
- 問い合わせ件数
- 自分で教材を足した人の割合
- コピーから最初の AI 採点までの所要時間
