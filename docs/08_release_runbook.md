# 配置と受入手順

現在はローカル実装まで。push・deploy・実API送信は実施していない。

## 初回配置（本人専用）

1. 自分用の新しいGoogleスプレッドシートを作成し、「拡張機能 → Apps Script」を開く。
2. プロジェクト設定でスクリプトIDを確認する。`src/.clasp.json`をローカルに作り、`{"scriptId":"新しいスクリプトID","rootDir":"."}`とする。日記アプリのIDを流用しない。
3. `src`で`npm ci`、`npm run build:data`、`npm run check`。`npx clasp login`で本人として認証し、`npx clasp show-file-status`で送信対象を確認、`npm run push`で配置する。
4. Sheetsを開き直し「英語訓練 → 初期設定」を実行して認可する。メニューが出なければApps Scriptエディタで`initializeTrainer`を実行する。
5. Webアプリとして新規デプロイする。実行者は自分、アクセスできるユーザーは自分のみ。`appsscript.json`もUSER_DEPLOYING/MYSELFで固定する。
6. Webアプリの設定画面で自分のGeminiキーを登録、AIを有効化する。初期値はAIオフ、30回/日。キーを教材シートに書かない。

Google側のAPI利用可否・無料枠・課金設定は使用するプロジェクトで確認する。モデル既定値は`env/config.yaml`。アプリの日次回数制限は課金停止機能ではない。

## 実環境の受入（未実施）

- 初期化を2回実行して重複せず、教材51件がある。
- PC/スマホで選択式回答→記録、自由記述→実AI採点→再判定。
- 先生/仲間/自由会話の開始→数ターン→終了→候補承認。
- 同じ要求の再送でAI回数・回答・会話が重複しない。
- AIオフ、キー未登録、日次上限で保存と停止理由を確認。
- 教材変更後も旧回答は旧版で再判定される。
- 実モデルの代表回答セットを人手採点と比較し、5判定の品質を校正する。
- 別アカウントからアクセスできないことを確認。
- 配布用コピーでスクリプトの紐付け・Properties・公開設定を確認。キーと学習記録を含む個人利用済みファイルを配らない。

コピー配布はこの受入後に行う。コピー先も各自のキー登録と本人限定デプロイが必要。コピーだけで設定完了する保証はしない。

## 更新・復旧

更新前にSheets全体をバックアップし、デプロイ版番号を記録。既存ユーザーの教材をenvで上書きしない。障害時は旧デプロイへ戻す。schema欠損を初期化で補修せず、バックアップと列定義を照合する。今回のschema v1には旧日記データの移行処理はない。
