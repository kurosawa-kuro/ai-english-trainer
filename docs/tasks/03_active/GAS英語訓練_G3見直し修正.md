# GAS英語訓練 G3 見直し修正

2026-10-25。ユーザーから重要作業として作業間違い・漏れの見直しを依頼された。既存のG3実装と移植構想、sampleを照合し、不具合を修正した。配布モデルA・G3の範囲を維持し、外部環境には配置していない。

## 主な指摘と修正

|重要度|問題|修正・回帰確認|
|---|---|---|
|高|WebアプリでgetActiveSpreadsheetに依存|初期設定で保存先IDを登録、実行時はopenById。activeなしのモックで検証|
|高|回答やAI出力の先頭=が数式として解釈される|RichTextで文字列保存。セル長・主キー不変も検査|
|高|pending再開がAIオフ・キー削除・日次枠を無視|設定を再検査、前日未送信予約を失効。同回答の並行採点を予約ロック内で拒否|
|高|ブラウザ保存を失うと保留会話・終了要求が復元できない|サーバーから元IDと本文を返し、記録から再開。PC/モバイル幅で保存消失→中止→再送を検証|
|高|失敗済み旧ターンが後から同じ会話順番へ書き込まれる|旧IDを再実行せず新IDを要求。AI予約前停止・成功結果保存後の再送は復旧可能|
|中|会話履歴が長いとsnapshot上限で進めなくなる|古い文脈から縮め、最新発話を保持|
|中|同時刻の採点をランダムIDで並べ替え、古い判定を表示|追記行順を確定順とし、能力集計も最新判定だけを採用。AI成功後に未確定の旧採点は再判定前に復旧|
|中|再チェックと次の回答が同時刻で新履歴から消える|ロック内で回答・リセットの記録時刻を単調増加にする|
|中|残り問題が少ないと3問間隔を確保できない|必要時だけ安定済みの問題を間に挟む。全問安定後は停止|
|中|必須表現のnot_applicableを合格扱い|retry_targetへ分類|
|中|下書き消失、復元後の保留本文未表示、中止で別要求も消す|入力保持・要求ごとの中止・サーバー由来要求IDを表示|
|中|入力IDが上限内でも内部接頭辞追加後に上限超過|外部操作IDを100文字までとし保存前に検査|

## 構想との対応

基盤分離・学習台帳・採点・会話・初期教材・再送の主要導線を再確認。漏れていた能力別の基本集計と安定クイズ数表示、Application単独のポート差替えテスト、キャッシュ障害・ロック競合・初期化中断の検査を追加した。

G4の自動計画・混同登録・人間観測・詳細診断は引き続き範囲外。教材の全追加例展開、参照元の全会話メトリクス、教材の自動昇格は未移植として残る。これらを実装済みとは扱わない。現行範囲は[G3仕様](../../specs/gas-trainer-v1.md)。

## 検証と残作業

Node検証、生成整合、Prettier、実Chromium（模擬GAS/Gemini）の1440px/390pxを実行。実環境の権限・Sheets・RichText保存・コピー配布・Geminiの採点校正・スマホ実機は未検証。実施手順は[配布手順](../../08_release_runbook.md)。既存日記・sampleは変更していない。
